# Tic-Tac-Toe (Android)

## Overview
A classic two-player Tic-Tac-Toe mobile game built for Android. This project serves as a practical application of software engineering principles, focusing on game logic algorithms, state management, and user interaction within a mobile environment.

## Features
* **Two-Player Gameplay:** Standard turn-based match on a 3x3 grid.
* **Custom UI Assets:** Replaced default Android elements with custom iconography, including unique designs for "X" and "O" markers and a custom app icon.
* **Win/Draw Detection:** Backend logic continuously evaluates board states to automatically declare a winner (horizontal, vertical, or diagonal) or a draw when all 9 boxes are filled.
* **Instant Reset:** Integrated a "Play Again" feature that clears the grid and resets the game state without requiring an app restart.

## Technologies Used
* **Platform:** Android
* **Language:** Java / XML
* **Environment:** Android Studio
